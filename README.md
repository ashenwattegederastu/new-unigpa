# University GPA Calculator

A full-stack University GPA Calculator web application built as a personal portfolio project.

## Tech Stack

### Frontend
- React with Next.js
- Nextra theme for layout and styling
- Modern React (hooks, functional components)

### Backend (coming soon)
- Jakarta EE with JAX-RS REST API
- JPA (Hibernate) for persistence
- PostgreSQL

## Features
- User authentication (register, login, logout)
- Manage multiple degrees
- Add modules with credits and grades
- Automatic GPA calculation
- Beautiful glassmorphism UI design
